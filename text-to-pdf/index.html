    Text to PDF — frequently asked questions

    Which file types can I convert?

    Any plain-text file: .txt, .md, .log, .csv, .json, .xml, .html source and similar.

    Will long lines be cut off?

    No. Long lines wrap onto the next line automatically.

    Can I use Hindi text?

    Yes, UTF-8 Hindi and all other scripts are supported.

    Is it private?

    Yes — the file is converted on your device.
